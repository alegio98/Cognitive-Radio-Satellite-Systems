# 🛰️ Cognitive Radio in Satellite Systems

This repository contains the source code and documentation related to my Bachelor's thesis:  
**"Applicazione di framework cognitive radio a sistemi satellitari"**  
conducted at **Università degli Studi Roma Tre**, Department of Computer Engineering (2018–2020).

## 🎯 Project Overview

The thesis explores how cognitive radio techniques can be applied to satellite communication systems to enable **dynamic spectrum allocation** and **context-aware adaptation**. This helps optimize bandwidth usage and improve signal reliability in complex or constrained environments.

Key objectives:
- Study of frequency adaptation and environmental sensing in satellite contexts
- Design of a conceptual prototype using cognitive radio principles
- Simulation and modeling of communication behaviors under variable conditions

## ⚙️ Technologies & Tools

- MATLAB / Java (for signal modeling and prototyping)
- Custom spectrum analysis scripts
- Scientific literature on SDR and satellite link adaptation
